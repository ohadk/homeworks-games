# שיעורי בית ועבודות לבית הספר

חומרי חזרה למבחנים, מסודרים לפי מבנה קבוע:

```
<שם הילד>/<מקצוע>/<תאריך>-<נושא>/
```

`index.html` בשורש = עמוד הבית: כל התרגולים לפי תאריך מבחן, עם ספירה לאחור למבחן הקרוב.
תרגול חדש = להוסיף תיקייה + שורה למערך `GAMES` שבעמוד הבית.
